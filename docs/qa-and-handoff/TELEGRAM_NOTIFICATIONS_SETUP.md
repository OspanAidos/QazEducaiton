# QazEducation — Telegram notifications v1

Этот документ относится к автоматическим уведомлениям через @QazEducationBot.
Полная установка Telegram-входа описана в `PRODUCTION_UPDATE_2026.md`.

## Что добавлено

- очередь `public.notifications` с привязкой к заявке;
- Edge Function `telegram-notify`;
- автоматическая отправка после первой/повторной подачи заявки;
- автоматическая отправка после действий администратора:
  - Передать комиссии;
  - Отправить на доработку;
  - Отклонить;
- комментарий администратора попадает в Telegram при доработке/отклонении;
- в админке отображается состояние последнего Telegram-уведомления;
- если отправка не удалась, администратор может нажать «Повторить отправку»;
- старое неотправленное уведомление отменяется, если по заявке появился более новый статус, чтобы участник не получил устаревшее сообщение;
- подготовлены шаблоны RU/KZ для результатов конкурса (grant / scholarship / top30 / reserve / not_selected) — они начнут использоваться, когда будет подключена публикация итогов.

## Установка

### 1. SQL

Supabase -> SQL Editor -> New query.

Запустить целиком:

`supabase/telegram-notifications.sql`

Ожидаемый результат: Success.

### 2. Deploy Edge Function

Из корня проекта:

```powershell
npx.cmd supabase functions deploy telegram-notify
```

ВАЖНО: для `telegram-notify` НЕ использовать `--no-verify-jwt`.
Эта функция вызывается только авторизованным участником или администратором.

Новый secret создавать не нужно. Функция использует уже существующий:

`TELEGRAM_BOT_TOKEN`

### 3. Перезапустить локальный сайт

```powershell
npm run dev
```

## Проверка №1 — подача заявки

1. Войти участником через Telegram.
2. Подать тестовую заявку.
3. После успешной подачи бот должен прислать «Заявка принята».

## Проверка №2 — действие администратора

1. Войти в `/admin`.
2. Открыть тестовую заявку.
3. Нажать «Отправить на доработку».
4. Написать тестовый комментарий.
5. Подтвердить действие.
6. Участник должен получить в Telegram сообщение с этим комментарием.
7. Внизу блока «Решение секретариата» должен появиться статус Telegram-уведомления «Отправлено».

## Если Telegram временно недоступен

Решение администратора всё равно сохраняется. Уведомление получает статус `failed` и остаётся в БД. В админке появится кнопка «Повторить отправку».

## Функции авторизации

После полной замены файлов проекта убедитесь, что опубликованы:

- `telegram-auth-start`
- `telegram-auth-status`
- `telegram-bot-webhook`

Команды публикации и правила для `TELEGRAM_WEBHOOK_SECRET` приведены в
`PRODUCTION_UPDATE_2026.md`. Авторизация не зависит от `telegram-notify`, но
все четыре функции должны быть опубликованы для полной работы сайта и
уведомлений.
