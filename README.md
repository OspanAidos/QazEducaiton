## Быстрый запуск на macOS

1. Установите зависимости:

```bash
npm ci
```

2. Проверьте наличие `.env.local`. Этот файл не входит в архив из соображений
   безопасности. Если его нет:

```bash
cp .env.example .env.local
```

3. Заполните `.env.local` значениями из Supabase Dashboard → Project Settings
   → API:

```text
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
```

4. Запустите сайт:

```bash
npm run dev
```

После любого изменения `.env.local` остановите сервер через `Ctrl+C` и
запустите его заново. Vite читает переменные только при старте.

На MacBook используется команда `npm`, а не `npm.cmd`.

Полный порядок SQL, публикации Edge Functions и контрольная проверка находятся
в `PRODUCTION_UPDATE_2026.md`. При обновлении с предыдущей версии этого архива

находится безопасный импорт 48 записей старого сайта.

Клиентский код поддерживает как новое имя
`VITE_SUPABASE_PUBLISHABLE_KEY`, так и прежнее `VITE_SUPABASE_ANON_KEY`.
Секретный серверный ключ и Telegram Bot Token нельзя хранить в `.env.local`.

## Данные подбора вуза

Подбор на `/match` обновлён по официальному списку обладателей образовательных
грантов на 2026–2027 учебный год. В клиентскую сборку попадают только
обезличенные агрегаты: группа образовательных программ, код вуза, минимум,
25-й/50-й/75-й процентили, максимум и размер выборки.

- используется общий конкурс и очная полная форма;
- сельская квота и сокращённая форма исключены;
- в интерфейсе показываются только пары «группа + вуз» минимум с тремя результатами;
- диапазон — центральные 50% результатов, а не вероятность поступления;
- 9 вузов каталога найдены в официальных итогах; Международный университет
  туризма и гостеприимства остаётся в справочнике заявки без выдуманного
  ориентира 2026–2027.

Для изменения только справочных данных подбора не требуются SQL или Edge Functions.
Для обновления QR-оплаты от 03.09 они обязательны — см. документ релиза выше.

## Важные ограничения

- API-ключ ApiPay и секрет вебхука хранятся только в Supabase Edge Function Secrets.
- Персональные документы находятся в приватном Storage.
- Комиссия не получает доступ к удостоверениям личности и документам законного
  представителя.
- Университеты представлены как образовательный справочник и не называются
  официальными партнёрами без подписанных документов.
- Перед публичным запуском юридические тексты должны быть утверждены
  организатором и проверены юристом Республики Казахстан.
